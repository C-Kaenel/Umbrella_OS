# Security Policy

Umbrella OS is an experimental personal project in Alpha. Only the latest commit on `main` is looked at.

## Reporting a vulnerability

Please do not open a public issue. Use the [Security Advisories](https://github.com/C-Kaenel/Umbrella_OS/security/advisories/new) page instead and include a description, steps to reproduce and the possible impact.

Reports are handled on a best-effort basis; there are no fixed response times.
